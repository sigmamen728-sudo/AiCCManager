# AiCCManager

AiCCManager is a Windows desktop AI assistant for chat, local models, and computer tasks. It started as a hobby project.

## Download

Get the Windows x64 ZIP from [GitHub Releases](https://github.com/sigmamen728-sudo/AiCCManager/releases). Extract the entire ZIP to a folder and open `AIComputerControl.exe`. The ZIP includes the .NET 8 Desktop runtime.

## Features

- Chat with Gemini, Groq, DeepSeek, custom API providers, and local models.
- Install engines, download models, and launch sessions in a single terminal from the app. Profiles include Ollama, AirLLM, Claude Code + Ollama, and Claude Code + AirLLM.
- Select Qwen2.5 Instruct 0.5B, 1.5B, 3B, or 7B for AirLLM. Claude Code + AirLLM supports text chat.
- Work with file attachments, MCP connections, skills, and plugins. Computer actions use the app's approval settings.
- Use light or dark mode and customize the sidebar.

Initial engine and model downloads need an internet connection. Model performance depends on the selected model and hardware.

Report bugs or share ideas in [Issues](https://github.com/sigmamen728-sudo/AiCCManager/issues).
